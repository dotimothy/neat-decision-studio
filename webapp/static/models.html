MLA model memory

–

Compiled graphs live in memory reserved for the MLA, separate from the board's Linux RAM and shared with any other application using the MLA. Only this app's models are counted here.

One model is on the MLA at a time: loading a model unloads the one that was there. Loading takes 3–10 seconds. Nothing is loaded on its own: the other pages use whichever model is loaded here, and wait while there is none.
